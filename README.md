# 🎮 Gamified Project

A Solidity-based decentralized application (dApp) that introduces a gamified approach to group project management. The smart contract enables project owners to create tasks, assign them to participants, and automatically reward contributors upon successful task completion. By leveraging blockchain technology, the platform ensures transparency, security, and trust in project collaboration.

---

## 🚀 Features

- 📌 Create and manage project tasks
- 👥 Assign tasks to participants
- ✅ Mark tasks as completed
- 🎁 Reward participants automatically upon task completion
- 🔒 Transparent and immutable task management using blockchain
- ⚡ Built with Solidity for decentralized execution

---

## 🎯 Vision

The **Gamified Project** aims to transform traditional group project management by introducing blockchain-powered incentives. Through a transparent and decentralized reward system, participants remain motivated to complete assigned tasks while project owners can efficiently manage workflows without relying on centralized authorities.

By combining task management with smart contract automation, the platform promotes accountability, collaboration, and fair reward distribution.
